Curated things worth keeping: papers, talks, tools, and references.

## Distributed Systems

- [Dynamo: Amazon's Highly Available Key-value Store](papers/distributed-systems/amazon-dynamo-highly-available-key-value-store-sosp2007.pdf) — SOSP 2007. The paper behind eventual consistency, consistent hashing with virtual nodes, quorum reads/writes, and vector clocks. Foundation for Cassandra, Riak, and DynamoDB.
